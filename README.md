# 🎥 YouTube Homepage UI Clone

This is a front-end project that replicates the design of the YouTube homepage using only HTML and CSS. It focuses on clean layout structures, accurate positioning, and visual details.

> **Note:** This is a static UI design project. There is no active backend or working search engine. It displays a set collection of videos directly on the homepage.

## ✨ Features
* **Accurate Layout:** Recreates the core components of YouTube, including the top navigation bar, the sidebar menu, category chips, and the video grid.
* **Responsive Design:** Built using modern CSS to ensure the page automatically scales and looks good on desktops, tablets, and mobile phones.
* **External Links:** The thumbnails, video titles, and channel names are fully clickable and open the actual, original content on YouTube in a new tab.
* **Channel Badges:** Includes custom verification ticks and official music artist badges next to creator names for a more realistic look.

## 🛠️ Built With
* **HTML5:** Used for setting up the semantic structure of the page.
* **CSS3:** Used for styling, smooth hover effects, and responsive alignments using Flexbox and Grid.

## 📂 Project Structure
* `youtube.html` — The main HTML file containing the page structure.
* `Styles/` — A directory for CSS files handling the layout design.
* `Thumbnails/` & `Profile/` — Folders for static video images and channel icons.
* `Icons/` — UI icons used across the navigation panels.

## 🚀 How to Open the Project
1. Download or clone this repository to your local machine.
2. Open the `youtube.html` file in any modern web browser to view the page.
